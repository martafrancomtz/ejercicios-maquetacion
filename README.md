# Ejercicios de maquetación

Ejercicios del Máster en Diseño Web y UI/UX (CEI), entre octubre de 2024 y enero de 2025. Todo está hecho desde cero con HTML, CSS y JavaScript, sin librerías.

## 1. Mosaico con CSS Grid · BEM y SUIT CSS
`ejercicio-asincrono-1-BEM/` · `ejercicio-asincrono-1-SUIT/`

La misma página, un mosaico de imágenes con cabecera y menú, maquetada dos veces con dos metodologías de nombres de clases, para comparar cómo organiza cada una el CSS:

- **BEM:** `header__imagen1`, `menu__item`, `mosaic__item`…
- **SUIT CSS:** la misma estructura con la convención de SUIT.

## 2. Componentes en JavaScript
`ejercicio-asincrono-3/`

Tres componentes de interfaz hechos con JavaScript:

- **Pestañas (tabs)**
- **Acordeón**
- **Lightbox**: galería de imágenes que se abre a pantalla completa.

## 3. Prueba técnica: maquetador trainee
`ejercicio-asincrono-4/`

Una prueba técnica real: reproducir un diseño a partir de un vídeo, con sus animaciones, a 1440 px y adaptado a tablet y móvil. El enunciado está en `ejercicio-asincrono-4/readme.md`.
